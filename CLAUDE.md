# Flappy Dragon Conqueror

Single-page canvas game. Open `index.html` directly (double-click / `file:///` works).

## Layout

- `index.html` — HTML shell: `<audio>` tags, HUD, buttons, modals; loads the CSS and JS below.
- `src/style.css` — all styles. Reference images from here as `../assets/images/<file>`.
- `src/js/` — game code (see below).
- `assets/images/` — only the images the game loads, plus `icon.png`. Big paintings and portraits are JPEGs: storybook pictures (`dance1/2` at 848×1264; `capture1/2` cropped to 752×1121 to drop the TV-style frame in the originals), noble portraits (`noble1`–`noble7`) at 720px on the long side, quality 82–85, made with macOS `sips` (e.g. `sips -Z 512 -s format jpeg -s formatOptions 85 in.png --out out.jpg`). The original PNGs are in `archive/source-art/`.
- `assets/audio/` — only the music/SFX the game loads (MP3/WAV/OGG/FLAC), plus the CC0 license note for the wing flap.
- `khaleesi0900.html` — untouched pre-refactor backup.
- `khaleesi0900-bundle.html` — generated single-file build. Don't edit it by hand.
- `archive/` — not used by the game. NOTE: `old-versions/` (earlier builds), `source-packs/` and `google-play-package/` (with **`signing.keystore`**) were moved out to `~/Desktop/flappy archive/`; `archive/old-versions/` here only holds `render-dragon-v1-original-sprite.js` (the cyan-winged sprite, also git tag `dragon-sprite-v1`). The list below is the original layout:
  - `old-versions/` — earlier builds and snippets. They expect assets in the root folder, so they won't play sound or show art.
  - `google-play-package/` — the old Android build (.aab/.apk), **including `signing.keystore`**. Keep it: you need that key to publish updates.
  - `store-listing/` — store screenshots.
  - `source-packs/` — downloaded SFX packs, extracted folders, source art (.psd).
  - `source-art/` — full-size originals of the storybook pictures and noble portraits (the old king/queen portraits are in `unused-assets/`).
  - `unused-assets/` — images and sounds the game doesn't reference. Move one back into `assets/` if you start using it.

## JS files (load order = `<script>` order in index.html)

They're plain classic scripts sharing one global scope. **Don't use ES modules** (`import`/`export`/`type="module"`); they break `file:///`.
Top-level code runs in load order, so anything a file uses *immediately* at load time must already be defined in an earlier file. Function bodies can reference anything.

1. `config.js`: constants, global state variables, DOM element refs, canvas + `resize()`, image loading, dragon/entity arrays
2. `audio.js`: `SoundEngine` class and the `sound` instance. Fire (`fireRoar()`) and the wing-knockback `bonk()` are synthesized in Web Audio (shared `noiseBuffer()`): fire is a noise "fwoosh" swept bright to dark with a low body and crackles (lighter when shots come within 0.12s); fire is kept quiet relative to the music (output gain 0.38). bonk is a falling boing, woody knock and click; at most one plays every `BONK_MIN_GAP` (0.22s), so a crowd or fast flapping makes one bonk, not a trill. `knightHit()` is still used for armor clangs, chests and the like.
3. `ui.js`: HUD updates, pause, level progression, score/hearts, save codes, share graphic, `resetGame()`
4. `entities.js`: `spawnObstacle()` (castles, archers, knights, trebuchets, Khaleesis, hearts), `triggerBeheadingCutscene()`
5. `input.js`: touch/mouse/keyboard input, menu click handling, button listeners
6. `render-sky.js`: sky gradient, starfield band, twinkling stars, full moon with the real near-side maria and Tycho rays, two cloud layers, far and near parallax castles. Static layers are cached offscreen per size and level (`bgLayer`); `hash2()` gives flicker-free noise.
7. `render-world.js`: ground, ground flames, battlements, archers and arrows
8. `render-characters.js`: Khaleesi, mounted HUD, castle walls (obstacles) with arched wooden doors (`drawWoodenDoor`), collectable hearts
9. `render-dragon.js`: `drawDragon()`, the blocky sprite from khaleesi0900.html, polished: crimson wings with a lighter sheen and maroon bones (the original had cyan wings; it is saved as git tag `dragon-sprite-v1` and in `archive/old-versions/`), brow ridge, fang, head highlight, spade tail tip, extra back spike, cream claws. While the gold shield is held it turns gold, glows, and holds the shield across its belly (`drawHeldShield`).
10. `render-enemies.js`: trebuchets, boulders, `drawKnights()` (villager and royal movement and states)
11. `render-people.js`: villager sprite (random headwear, beard, apron, skin tone; pitchfork or torch) and king/queen sprites
12. `render-masonry.js`: `drawMasonry()`, with 4 cached stone styles (brick, fieldstone, ashlar with quoins, Flemish bond) plus weathering; charred versions get soot and embers
13. `effects.js`: flame renderer, breath, archer detail, particles, debris, floating text
14. `screens.js`: level dialogue, beheading cutscene, game-over screens
15. `boss.js`: siege-engine boss state, geometry, archer spawning, wave helpers and tuning constants, burn helpers
16. `boss-update.js`: `updateBossLogic()`, covering movement, wheels, cannons, archer waves and flame hits
17. `boss-render.js`: boss drawing helpers (open-spoked wheels, the wide wheeled platform `bossChassis`, rear timber-and-steel scaffolding with a crane arm `bossRearScaffold`, stone gargoyles with glowing eyes `bossGargoyle`, etc.), wheel debris (`bossRocks`), and `renderBoss()`
18. `boss-intro.js`: the cinematic between the level 3 fireworks and the boss (state `BOSS_INTRO`): the tower smashes through a distant wall, then the dragon and Khaleesi react. Tap skips it. Also `currentRumbleLevel()` (wheel rumble sound) and `sceneShake()` (camera shake).
19. `knights.js`: small armored knights (level 4+: fire-heat timer, spear thrust), gold knights (level 5: protect/attack actions, grab and drop) and the gold shield the dragon carries (`obstacleHit()`, `dragonShielded()`). The shield also blocks small-knight spears and gold-knight swords, and the dragon turns gold and glows while holding it. Gold knights always act in the order `GK_ACTION_ORDER` (sword swing, shield, charge). Shield blocks call `shieldDeflect()` (clang sound, flash, sparks); arrows bounce off.
20. `treasure.js`: treasure chests (open, locked, smashed treasure), the treasure score multiplier, `clearLevelExtras()`, and the `updateLevelExtras()` / `drawLevelExtras()` / `drawDragonCarried()` hooks that main.js calls
21. `prologue.js`: the two peaceful levels before L1 (meadow `PRO_MEADOW` = -1, village `PRO_VILLAGE` = 0, so `inPrologue()` is `currentLevel <= 0`), Khaleesi's scripted lines (`PRO_SCRIPT`), sheep snatching and the gold pouch, the ballista capture (state `CAPTURE`, timings `CAP_*`) and the "captured" message (state `CAPTURED_MSG`). Also `sunnyScene()`, `fireDisabled()`, `khaleesiRidingNow()`.
22. `render-prologue.js`: sunny sky, sun, clouds, rolling hills (cached tiles), wildflower ground, birds, sheep, shepherds (sitting with a lute or standing with a crook), maypole dancers, thatched huts, wells, hens, village crowds, the slavers' castle with its ballista and knight crew, the capture overlay, and `drawStoryMessage()` (the typed message screens)
23. `cathedral.js`: level 2's optional cathedral encounter (logic). The tower (`cathedral`, `cathedralGeom()`, `cathSolidAt()`) comes at `CATH_AT` (135s) and holds back normal towers (`cathedralBlocksSpawn()`); its stone and roof cost a heart once, its window band is open, and flying into the window starts state `CATHEDRAL`. The cutscene is a list of steps (`cathStartSteps()`, then `cathRestSteps()` or `cathFightSteps()`, lines in `CATH_LINES`), run by `updateCathedralScene()` and advanced by `cathedralTap()` (R/F keys pick at the choice). REST gives a heart container (`maxLives`, up to `CATH_MAX_LIVES`), then the thoughts, Clement and the teleport; back in the level `cathDread` darkens the edges for the rest of level 2 and `cathAfter` shows a thought. `cathCinematic()` hides the HUD.
24. `render-cathedral.js`: the tower (red tiled roof, stained-glass window), the cathedral interior painted once into a layer three screens tall (`cathInterior()`: vault, rose window, lancets, angel statues `drawAngelStatue()`, candelabras, chandelier, arcade, altar, carpet; candle flames drawn live), `drawCathedralScene()` (fall, sleep, dream, heart container, Clement `drawClement()` with his portrait `clementPortrait()`, sphere and teleport spell, dialogue boxes `drawCathDialogue()` with the REST / FIGHT ON buttons) and `drawCathedralHUD()` (dread vignette, thought bubble, fade-in).
25. `boss-fall.js`: the boss ending (state `BOSS_FALL`, started by `startBossFall()` when all three sections are charred). Phases: `collapse` (the tower sinks, burning, into a pit, `bfPit()`, drawn by `drawBossFallScene()` with `renderBoss()` clipped and translated by `bossFall.sink`; a lone archer climbs onto the turret roof at `BF_ARCHER_AT` and fires a chain arrow at `BF_FIRE_AT`, `drawChainLinks()` / `drawChainArrow()`, homing on `bfChest()`), `drag` (red flash, cracked heart, the chain reels him down after the tower), `cavern` (`updateBfCavern()` / `drawBossFallCavern()`: he falls through darkness for `BF_FALL_LEN` frames chained to the burning tower drawn below him at `BF_TOWER_SCALE`, embers, flames, smoke and burning chunks streaming up past him; the glowing mushrooms, walls and jellyfish fade in with `cave.bio`; then the tower and he hit the floor), `floor` (a step list like the cathedral's: `bfFloorSteps()`, then `bfAcceptSteps()` or `bfRejectSteps()`, lines in `BF_LINES`; `drawBfFloor()` shows the burning wreckage, the blood pool `floor.blood`, his dying thoughts, Sarai's portrait fading like a memory `saraiMemory()`, black, waking with glowing creatures `drawCavernLife()` / `drawGlowFlyer()` above, and Brown Jenkins `drawJenkins()` with his portrait `jenkinsPortrait()`). ACCEPT: Nyarlathotep's healing `drawJenkinsHeal()` (arrow and blood fade), a heart container (+1 `maxLives`), the debt dialogue, then `startCaveLevel(1)`. REJECT: game over with `jenkinsRejected`; its only button, CONTINUE, calls `finishBossFall()` (BOSS_CLEAR dialogue, level 4). Taps: skip the collapse and fall after `BF_SKIP_AFTER`, then advance the floor steps (A/R keys at the choice). Sounds: `collapseBoom()`, `chainRattle()`, `pierceHit()` in audio.js.
26. `cave.js`: the two cave levels (`caveLevel` 1 or 2, `currentLevel` stays 4; `startCaveLevel()`, `updateCave()`, durations `CAVE_DURATIONS`, titles `CAVE_TITLES`, save-code characters `CAVE_CODES` "C"/"D"). The tunnel is smooth noise: `caveMid()`, `caveGap()` (narrower in cave 2), `caveCeilAt()` / `caveFloorAt()`; touching rock costs a heart and recenters him. Torches every few hundred px (`caveTorchHead()`); a flame lights one (+10). After cave 2, `startSurfaceScene()` (state `SURFACE`, `SURFACE_LEN`) then the CAVE_CLEAR dialogue and level 4.
27. `render-cave.js`: `drawCaveScene()`: the tunnel drawn in full light, then a darkness mask (`caveMaskCanvas()`) with holes for his faint glow, his flames and lit torches; torch flames, the glowing creatures (`drawCaveLife()`, clipped to the tunnel) and score texts are drawn over the darkness. `drawSurfaceScene()`: up a shaft toward the light, then out of a cave mouth into level 4's night sky.
28. `main.js`: `triggerHit()`, level celebration, `update()` (physics and collisions), `render()`, `loop()` (starts the game; must stay last). `loop()` runs a real-time clock: always 60 game steps per real second (`GAME_STEP_MS`), whatever the screen rate, so 30 fps phones (iPhone Low Power Mode) don't run in slow motion and 120 Hz screens don't run fast. Much game logic lives inside draw functions (peasants, arrows, flames, particles, pickups, `dragon.wingState`), so catch-up steps call `renderLogicOnly()`: `render()` with the drawing methods in `NO_DRAW` stubbed out (`save`/`restore` stay real). `logicOnlyPass` is true during it. Count anything new by game steps, not by drawn frames.

## Level flow

Opening screen (sunny; Sarai invites Cyndraxx to fly, with a DRAGON QUEEN SARAI name plate under her portrait: `drawStoryMessage()`'s `nameTag`) → start menu → Meadow (100s+) → Village (95s) → ballista capture → "captured by the slavers" message → L1 (90s) → L2 (180s) → L3 (150s) → fireworks → siege-tower cinematic → boss → boss ending (pit, cavern, Brown Jenkins) → CAVE 1 (80s) → CAVE 2 (90s) → climb to the surface → L4 (240s) → L5 (240s) → victory. Durations are in `LEVEL_DURATIONS` (config.js); the transitions are in `checkLevelProgression()` (ui.js).

- **Prologue (prologue.js):** sunny daytime, rolling ground (`proTerrainH()` / `proGroundY()`, up to `PRO_TERRAIN_MAX` 100px above the flat ground line, lower in the village; sheep, people, huts and the lane follow it), opening-screen music (`uiMusic`) until the net drags them over the wall, then the beheading music (`captureSadMusic()`) for the fall, the story images and the "captured" message, fire disabled (the FIRE button is greyed out), Khaleesi rides on Cyndraxx's back with no invincibility. Hitting the rolling ground still costs a heart; the top of the screen just stops you. Dying restarts the same prologue level.
  - **Meadow:** sheep, shepherds, birds, maypole dancers. At 66s Khaleesi asks for a sheep; fly low over one to grab it (`PRO_SNATCH_DX`/`DY`). She drops a gold pouch to the nearest shepherd. Eating the sheep scores `PRO_PTS_SHEEP` (250) and refills any lost hearts. The meadow ends after 100s, once the sheep has been eaten, then fades into the village.
  - **Village:** solid thatched huts (touching one costs a heart), crowds that wave at the dragon, children, hens, lute players. At 32s the **spring festival** arrives (`proSpawnFestival()`): a great thatched hall beside a town square with the maypole, bunting and dancing townsfolk, on levelled ground (`proFlats`). Khaleesi suggests landing on the roof and a LAND HERE arrow appears. As the hall comes in, the world scroll eases from `PRO_SPEED` (2.5) down to `FEST_APPROACH_SPEED` (1.1) so the roof is easier to hit (`proSpeed()`); the dragon's drift back to `baseX` slows by the same ratio, so it doesn't slide backward over the ground. Touching the hall lands Cyndraxx on the ridge (no damage, `PRO_PTS_ROOF` 500 points); the world stops, the view glides so the hall and square fit, they sing with the crowd, and the FIRE button turns into a blue SING button (`festSing()`: a hop and flap, a burst of notes and hearts, the crowd jumps, a random pentatonic chime from `playSingChime()`, `PRO_PTS_SING` 50 points per press), then the storybook shows `dance1.jpg` and `dance2.jpg` (tap to advance), then Khaleesi says they should journey on and Cyndraxx takes off. The level clock pauses from the festival's arrival until take-off. Missing the roof brings the festival round again. At 95s the slavers' castle rolls in and the capture plays with no player control: the ballista fires a big square net (`drawSquareNet()`) that wraps Cyndraxx and Khaleesi together, the rope drags them over the wall, then a wide shot shows them at normal sprite size tumbling down past the inside of the castle wall, bound in the net (`drawCaptureFall()`, wall from `drawFallWall()`), then `assets/images/capture1.png` (Khaleesi cut out of the net and dragged away) and `capture2.png` (Cyndraxx wakes and escapes), about 4.5s each (`CAP_IMG_FRAMES`) with captions; a tap moves to the next image. The HUD and controls are hidden from the close-up on (`.cinematic`). It ends on the old splash text (`fullStoryText`), then the level 1 intro dialogue.
- **Music:** levels 2 and 5 play the beheading music (`cutsceneMusic`) instead of the normal level music (`updateMusicState()`, audio.js).
- **Small knights** appear from L2 (25% of towers in L2-3, 40% in L4, 60% in L5) and never share a tower with peasants. They need `SK_BURN_FRAMES` (120) of unbroken fire contact to die.
- **Cathedral (L2, optional):** at 135s a tall tower with a red tiled roof and a great stained-glass window at mid-screen height comes by, with no hint. Flying into the window (no damage) plays the cathedral cutscene with the village music (`uiMusic`): Cyndraxx falls through a vast golden cathedral and lands on the carpet; his portrait is `assets/images/cyndraxx1.jpg` (a close crop of his face from `dance1.jpg`: 140px square at x 300, y 56, scaled to 256). He says he might rest; REST or FIGHT ON. FIGHT ON fades back to the level. REST: he sleeps, dreams of the festival (`dance1/2`), wakes to a heart container (+1 max heart, `maxLives`), doubts Sarai and cries, then Clement the Simple appears, Cyndraxx's giant breath is stopped by Clement's iridescent sphere, and Clement teleports him back into the level with a lingering dread. `K` warps to level 2 just before it. Save codes don't store the extra heart.
- **L4:** level 3 rules with more small knights. Emerald sky, violet torches, deep red archways.
- **L5:** only the longest towers, no trebuchets, peasants or royals, 3-4 archers per battlement, firing in synchronized "LOOSE!" volleys (`ARCHER_VOLLEY` in render-world.js), small knights plus one gold knight at a time. Golden dusk theme. Khaleesi explains gold knights and the shield on the first encounter, then only 15% of the time (`goldKnightTalk()`, knights.js).
- **Chests** can appear on any level (`CHEST_*` constants in treasure.js). A dropped locked chest breaks from any height: on a tower it leaves a treasure pile to grab, and on a battlement or the ground it pays out at once. They are drawn at `CHEST_SCALE` (2.2x). Every break or pickup plays `showTreasureFX()`. Chests are drawn before archers, peasants, royals and knights (`drawLevelChests()`, called right after the battlements), so a guard next to a treasure is always in front of it. During the level-clear celebration `chestsFollowWorld()` keeps chests on their towers and battlements (and a carried chest with the dragon).
- **Debug keys:** `1`–`5` warp to that level, `6` village just before the festival, `7` meadow, `8` village, `9` ballista capture, `B` starts the boss, `I` plays the boss intro cinematic, `C` plays the level-clear celebration, `K` level 2 just before the cathedral, `E` the boss ending, `J` Brown Jenkins, `U`/`Y` cave 1/2, `H` the climb to the surface.

## Boss tuning (boss.js / boss-update.js)

- The top of the screen is only a ceiling in the boss fight: the dragon stops there with no damage and no recentering. The ground still costs a heart.
- The tower holds its spot on screen but lunges toward the dragon (up to `BOSS_CHASE_AHEAD` of the screen width) and falls back (`BOSS_CHASE_BACK`). The ground scrolls at `BOSS_ROLL_SPEED` (9) and the sky at `BOSS_BG_SPEED` (2.2). The wheels judder, throw dirt and stones, and play a low rumble (`sound.setRumble()`).
- The boss fight plays the beheading music (`cutsceneMusic`).
- Archers come in waves. The first wave is 14 (`BOSS_FIRST_WAVE`), and each later wave adds `BOSS_WAVE_GROWTH` (max `BOSS_MAX_ARCHERS`). The next wave marches out `BOSS_REINFORCE_FRAMES` (8s) after the last one finished climbing, even if it is still alive (unless `BOSS_REINFORCE_MAX_ALIVE` are alive). Wiping out a wave opens the center for `BOSS_WINDOW_FRAMES` before the next wave. Volleys every `BOSS_VOLLEY_CYCLE` frames.
- The center opens while no archer is standing ready on the platform: after a wave is cleared (for `BOSS_WINDOW_FRAMES`), and while the next wave is still climbing.
- Each flame kills one archer, and one breath kills at most `BOSS_KILLS_PER_SHOT` (flames carry a `shotId` set in `shootFire()`).
- Damage per flame is `FLAME_DAMAGE` (0.6, top and bottom cannons) and `MID_DAMAGE` (1.2, center) in `boss-update.js`. Each section has 100 HP. Cannons reload every `BOSS_CANNON_RELOAD` (160) frames.

## Build

```bash
./build.sh
```

This inlines `src/style.css` and `src/js/*.js` (in `index.html` order) into `khaleesi0900-bundle.html` for GitHub Pages and PWABuilder. It uses only stock macOS bash and sed; this Mac has no system Python 3. The bundle still loads media from `assets/`, so deploy it alongside that folder.

## Other behaviors

- **Invincible (Khaleesi riding):** reaching her plays `showKhaleesiSplash()` (render-characters.js), a one-second splash that freezes the game on a snapshot of the last frame. While waiting on a tower she has a pulsing white-gold additive halo with twinkling sparkles (`drawKhaleesis()`), so her red hair stands out. While riding she sits on Cyndraxx's back, in the same seat as the prologue ride (`drawDragon()`). Touching villagers, small knights or gold knights kills them.
- **Hearts refill** to `maxLives` (3, plus one for the cathedral's heart container and one for Brown Jenkins' bargain, up to `CATH_MAX_LIVES` 5) whenever a level is cleared (`startLevelCelebration()`, ui.js, which also covers the boss) and when the meadow ends.
- **Background:** switching to another app or tab (`visibilitychange`/`pagehide`, end of audio.js) pauses all music and sound (`sound.hidden`, AudioContext suspended) and pauses PLAYING or BOSS. Coming back leaves the game on the pause menu, which is silent (`updateMusicState()` stops all music while PAUSED); resuming picks the music up where it stopped.
- **Beheading (noble heads):** beheading a king or queen shows a noble portrait of the right sex (kings get a man, queens a woman: the `female` flag on each `NOBLES` entry, `randomNoble(type)`; `NOBLES` and `drawNoble()` in config.js; each entry has a `face` crop and a `full` square crop), which zooms in to the head, with "YOU'VE TAKEN A NOBLE!". Each collected head remembers its portrait (`royalHeadNobles`, parallel to `royalHeadTypes`), shown on the pause and game-over screens ("NOBLE HEAD CONTINUES"). Heads loaded from a save code get random portraits of the right sex.
- **Resume:** `resumeFromPause()` (ui.js) restores PLAYING or BOSS and gives a free flap.
- **Level dialogue:** the portrait top is `LEVEL_DIALOGUE_PY` (150, screens.js; input.js uses it for the button tap area) so the title stays below the score and hearts; "LEVEL CLEARED!" is drawn no higher than y=125.
- **Pause menu:** the save-code modal's RETURN button goes back to the pause menu. The beheading cutscene's RETURN TO GAME button appears only after the animation finishes (`CUTSCENE_BUTTON_FRAME`).
- **Save codes:** 12 characters shown as `XXXX-XXXX-XXXX` (ui.js): score (5 chars, up to 60,466,175), kings (1), queens (1), villagers (3), level (1), check character (1, catches typos). Dashes, spaces and lowercase are ignored when loading, and old 6- and 7-character codes still load. While in the boss fight (or paused in it) the level character is `B` (`SAVE_CODE_BOSS`), and loading that code starts the boss fight. In the prologue the level character is `M` (meadow) or `V` (village); in the caves `C` (cave 1) or `D` (cave 2), and loading those starts that cave. Continues come from the beheaded kings and queens stored in the code.
- **Boss ending (boss-fall.js):** beating the boss no longer plays the level-clear celebration: the tower collapses into a pit, a lone archer's chain arrow pierces Cyndraxx's heart and drags him in, he falls chained to the burning tower through a cavern whose glowing life appears gradually, lands among the wreckage, bleeding, thinks of Sarai and fades to black, wakes, and Brown Jenkins (a possum with a human face and hands, the adjudicator of Nyarlathotep) offers to save him. ACCEPT: healed, +1 heart container, the debt (the Great Old Ones, the Angel that Weeps growing inside Clement the Simple), then CAVE 1 and CAVE 2 (dark tunnels lit only by his flame and the torches he lights, no enemies), the climb to the surface, the OUT OF THE DEPTHS dialogue and level 4. REJECT: game over, then CONTINUE goes straight to level 4. Boss music (`cutsceneMusic`) plays through all of it, the caves and the climb. Debug: `E` the boss ending, `J` the cavern floor (Brown Jenkins), `U` cave 1, `Y` cave 2, `H` the climb to the surface.
- **Boss chassis:** the tower rides on a deck wider than the tower (`over` in `bossGeom()`, 16% of the tower width per side) on two big wheels. The stone lower section ends at `deckTop`. The deck and its spiked front beam count as part of the lower section for hits and collisions.
- **Boss:** two archer platforms (`platY` with 3 rows, `platY2` with 2 rows in `bossGeom()`). New archers fill whichever platform has fewer.

## Naming

- The heroine is **Dragon Queen Sarai** in every player-facing string (story text, splash "DRAGON QUEEN SARAI RIDES!", stats, manifest). Never write "Khaleesi" in visible text; code identifiers (`khaleesiMounted`, `showKhaleesiBanner`, `khaleesi1.png`, etc.) still use the old name. Her portrait is `assets/images/sarai1.jpg` (facing forward) and `sarai2.jpg` (glancing aside), the user's paintings shrunk to 512px (1024px originals in `archive/source-art/sarai/`; the earlier pixel-art version and its `draw.py` are there too). Every dialogue screen draws its own border, so the portraits have no frame. The small sprite (`drawKhaleesiSprite()`) uses the same colors. The old Daenerys-like `khaleesi1/2.png` are in `archive/unused-assets/`. In the storybook pictures (`dance1`, `dance2`, `capture1`) Sarai was recolored (plus hand-picked touch-ups in `FORCE`, matching the user's own paint-over; their 429px copies are in `archive/source-art/sarai/user-touchups/`) from the white-haired, blue-dressed originals in `archive/source-art/` to copper hair and a green dress by `archive/source-art/sarai/recolor.py` (polygons around her per picture; convert to BMP with `sips` first, since there is no PIL).
- The dragon is **Cyndraxx** (renamed from Syraxx, which was too close to a House of the Dragon dragon).
- Kings and queens are called **nobles** in visible text, never "royals" (code still uses `isRoyal`, `royalHeads`).
- All dialogue, story text and captions are plain text: no quotation marks, parentheses or italics (`renderMountedKhaleesiHUD` also strips any `"` from banner text).
- Brown Jenkins and Nyarlathotep come from H. P. Lovecraft (public domain). Long titles use `fitFont(text, px, maxW)` (config.js) so they shrink to fit narrow phones.
- Speech bubbles are sized to their text: `drawSpeechBox(lines, cx, y, px, lineH, color, shown)` and `speechBoxHeight()` (config.js) for the opening/captured message, the level dialogue (`LEVEL_SPEECH` in screens.js, which input.js also reads for the button tap area) and the no-head game-over popup; the in-game banner (`renderMountedKhaleesiHUD`) and boss-intro bubble measure their own wrapped lines.
